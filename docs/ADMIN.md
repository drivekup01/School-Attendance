# บทบาทผู้ดูแลระบบ

## การตั้งบัญชี

เพิ่ม role string เป็น admin หรือ teacher ใน attendance_teachers/{Firebase Auth UID}
บัญชีต้อง active และ email ต้องตรงกับบัญชี Google ที่ยืนยันอีเมลแล้ว
การสร้างบัญชีหรือเปลี่ยน role ยังทำผ่าน Firebase Console / trusted Admin SDK เท่านั้น
หน้าเว็บเพิ่มสิทธิ์ admin ให้ตนเองหรือผู้อื่นไม่ได้

## หน้า admin.html

- เตรียมห้องเรียน โดยยังไม่ต้องมีนักเรียน
- เพิ่ม UID และชื่อครูในรายการมอบหมาย ชื่อต้องตรงกับ attendance_teachers
- มอบหมายห้องเข้าแถว คาบประจำ หรือสอนแทน พร้อมวันเริ่ม–สิ้นสุด
- เลือกสิทธิ์ความประพฤติแยกอย่างชัดเจน ไม่ให้โดยอัตโนมัติ
- ปิดงานมอบหมายโดยไม่ลบประวัติ

การเพิ่มงานจะเขียน assignment และ ACL ใน transaction เดียว
การปิดงานหยุดการเช็คชื่อของ assignment นั้น แต่ไม่ถอน ACL รายห้อง เพราะครูอาจมีงานอื่นในห้องเดียวกัน
หากต้องถอนสิทธิ์อ่านห้อง/ความประพฤติทั้งหมด ให้ตั้ง attendance_access/{uid}/classes/{classId}.active เป็น false ใน Console
API admin-store มี revokeClass สำหรับการพัฒนาหน้าระงับสิทธิ์ในขั้นถัดไป

ข้อมูลนักเรียนยังเพิ่มภายหลัง จึงยังไม่มีหน้าเพิ่ม/นำเข้านักเรียนในรุ่นนี้
ยังไม่มีการเชื่อม School-OS ตารางสอนอัตโนมัติ หน้านี้ใช้มอบหมายคาบโดยผู้ดูแลก่อน

## ข้อมูลส่วนตัว

admin อ่าน assignment และข้อมูลห้อง/การเข้าเรียนทั้งหมดได้ แต่ private profile ที่มีอีเมลครูยังอ่านได้เฉพาะเจ้าตัว
attendance_directory เป็นรายการชื่อครูและ active เท่านั้น ไม่เก็บอีเมล และอ่านได้เฉพาะ admin
ครูทั่วไปอ่านห้อง/คาบของตนตาม ACL และแก้คะแนน/การเช็คชื่อของผู้อื่นไม่ได้
ผู้ดูแลก็ไม่เขียน marks ในนามครูคนอื่นผ่าน browser

## ก่อนเปิด production

ต้อง Publish Rules v2 ที่รวมกฎเดิมครบ, เพิ่ม profile สองบัญชีผ่าน Console และเปิด GitHub Pages
เว็บตั้ง databaseReady เป็น true แล้ว แต่บัญชีที่ยังไม่มี profile จะได้รับ permission denied โดยไม่มีข้อมูลรั่ว
ยังต้องทดสอบ Google login ของผู้ดูแลและครูจริงบนโดเมน Pages

## การทดสอบ

17 กลุ่มผ่านใน emulator: 14 กลุ่มเดิม + admin permissions + admin-store integration + validation ของ metadata
มีกรณีปฏิเสธ self admin, teacher เขียน metadata, อ่าน private profile ครูอื่น, ปลอมชื่อครู,
เปลี่ยนเจ้าของ assignment, field เกิน schema และระงับ ACL แล้วอ่านรายชื่อไม่ได้
UI demo ทดสอบเพิ่มห้อง เพิ่มครู มอบหมาย และปิดงานแล้ว

Rules ชุดนี้ยังเป็น prototype ที่ต้องตรวจทานก่อนเปิดใช้วงกว้าง
