# สรุปเข้าแถวเช้าวันนี้

หน้าหลักแสดงยอด มา สาย ขาด ลา และยังไม่เช็คจากงานเข้าแถวเช้าเท่านั้น เลือกสถานะแล้วเลือกห้องเพื่อดูรายชื่อได้ บัญชีทั่วไปดูอย่างเดียว งานเช็คชื่อ/แก้ผลยังใช้สิทธิ์เดิม

บริการ `attendanceOverview` เป็น Firebase callable ใน codebase `school-attendance` ตรวจ Google email ที่ยืนยันแล้วและบัญชีโรงเรียน `@kbws.ac.th` หรือสมาชิกที่ผู้ดูแลอนุมัติใน `school_users` / `attendance_teachers` บัญชีที่ถูกระงับและผู้ไม่เข้าสู่ระบบอ่านไม่ได้ ไม่เปิด Firestore roster ให้สาธารณะ

วันปัจจุบันคำนวณที่เซิร์ฟเวอร์ด้วยเวลาไทย ไม่รับคำขอวันอื่น คำนวณจากรายชื่อที่เปิดใช้และห้องปี/ภาคเรียนล่าสุดของแต่ละชื่อห้อง นับนักเรียนครั้งเดียวต่อห้องโดยใช้ผลบันทึกล่าสุดเมื่อมีครูหลายคน ข้อมูลรายวิชาไม่ถูกนับ ผลที่ยังไม่บันทึกไม่ถือว่าขาด

คำขอ summary ส่งเฉพาะยอดรวมและยอดต่อห้อง คำขอ details ส่งเฉพาะเลขที่ เลขประจำตัว ชื่อ และสถานะของห้องที่เลือก ไม่มีหมายเหตุส่วนตัวหรือข้อมูลครู การค้นหาเป็นการอ่านข้อมูลปัจจุบัน ไม่เก็บรายชื่อใน service worker หรือ localStorage

ทดสอบ: `node --test functions/test/overview.test.cjs`

เผยแพร่: `firebase deploy --only functions:school-attendance:attendanceOverview --project school-budget-3e69d`

หน้าเว็บจริงไม่แสดงแถบแนะนำ/ลิงก์โหมดสมมติ โหมด `?demo=1` ยังแสดงคำเตือนเพื่อแยกข้อมูลสมมติออกจากข้อมูลจริง ใช้ `?demo=1&view=viewer` ตรวจรูปแบบบัญชีทั่วไปได้
