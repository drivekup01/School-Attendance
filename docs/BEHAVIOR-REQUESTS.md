# แบบคำร้องขอเพิ่มคะแนนความประพฤติ

## แบบฟอร์ม

แปลงโครงสร้างจากแบบคำร้อง Word ที่ผู้ใช้ให้มา โดยไม่คัดลอกชื่อรายบุคคล วันที่เก่า หรือรายชื่อนักเรียนในตัวอย่างเข้าเว็บสาธารณะ

ข้อมูล: วันที่ยื่น ผู้ยื่นตามบัญชีที่ยืนยันแล้ว หน้าที่ กิจกรรม สถานที่ ช่วงวันที่ คะแนนที่เสนอ ประเภทหลักฐาน รูปแนบ และรายชื่อจากฐานจริง

ตารางเพิ่มรายคนหรือเพิ่มทั้งห้องในคำร้องได้ สูงสุด 100 คน รวมหลายห้องตาม ACL ผู้ยื่น การเพิ่มรายชื่อในคำร้องไม่ใช่การบันทึกคะแนนแบบกลุ่ม

## สิทธิ์และขั้นตอน

- ผู้ยื่นต้องเป็นครูที่มีบัญชี active และอ่านห้องได้ หรือผู้ดูแลความประพฤติ
- ครูอ่านได้เฉพาะคำร้องของตน ผู้ดูแลความประพฤติอ่านคำร้องเพื่อพิจารณาได้
- pending: ยื่นคำร้องแล้ว ยังไม่มีคะแนนเปลี่ยน
- approved: สถานะจากระบบเดิม ผู้ดูแลดำเนินการให้เสร็จได้โดยไม่ต้องยื่นใหม่ และคงข้อมูลผู้อนุมัติเดิม
- awarded: ผู้ดูแลอนุมัติแล้ว ระบบเพิ่มคะแนนให้รายชื่อทั้งหมดอัตโนมัติใน transaction เดียว ป้องกันการเพิ่มซ้ำ
- ใช้สิทธิ์ผู้ดูแลความประพฤติที่ตั้งไว้ให้ manatchai.si@kbws.ac.th เท่านั้น ไม่ให้ identityAdmin หรือ attendanceAdmin อนุมัติโดยอัตโนมัติ
- การเพิ่มคะแนนทุกครั้งต้องใช้แบบคำร้อง รวมถึงผู้ดูแล เมนูบันทึกคะแนนเดิมใช้ลดคะแนนเท่านั้น
- ไม่มีการเติมลายเซ็นหัวหน้างานหรือผู้อำนวยการจากระบบ แบบพิมพ์คงช่องลงนามว่างแยกจากบันทึกอนุมัติในระบบ

## ข้อมูลและรูป

Callable attendanceBehaviorRequests จัดการ list, detail, photo, submit, approve, award ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ทุกครั้ง

เก็บ metadata ใน attendance_behavior_requests/{id} และภาพที่ย่อแล้วใน photos/{photoId} เป็นเอกสารส่วนตัวขนาดจำกัด เพื่อใช้กฎ deny เดิมและไม่เปิดภาพเป็น public URL

รูปสูงสุด 4 รูป JPEG/PNG หลังย่อไม่เกิน 256 KB ต่อรูป แนบจากเบราว์เซอร์ได้ JPG/PNG/WebP โดยแปลงภาพเป็น JPEG และไม่ส่ง metadata ต้นฉบับ

คำร้องและรูปบันทึก transaction เดียว ไม่บันทึกคะแนนตอนยื่น เมื่ออนุมัติจะบันทึกสถานะและคะแนนพร้อมกัน คะแนนจากคำร้องเก็บ sourceRequestId เพื่อย้อนกลับเอกสารต้นทางได้

การส่งซ้ำใช้ requestId เดิมและ digest ของข้อมูลเพื่อป้องกันคำร้องซ้ำ กดอนุมัติซ้ำตรวจ state awarded ก่อนสร้าง ledger

## การตรวจสอบ

node scripts/check.mjs
node --test functions/test/*.test.cjs tests/*.test.mjs

ทดสอบ browser ด้วยข้อมูลสมมติ: กรอกข้อมูล เพิ่มนักเรียน แนบรูป ยื่นคำร้อง อนุมัติ เพิ่มคะแนน และแบบพิมพ์ ไม่สร้างคำร้องหรือปรับคะแนนนักเรียนจริงในการทดสอบ

Firestore Rules ปิด browser create/update/delete ของคะแนน การเขียนต้องผ่าน callable เท่านั้น อนุมัติไม่สำเร็จจะไม่บันทึกทั้งสถานะและคะแนน
